# Clearvoice AAC MVP

A no-build, browser-based interactive AAC prototype. Open `index.html` in a modern browser.

It includes a stable core vocabulary board, quick and emergency phrases, a word finder, spelling mode, message composition with undo/clear, browser text-to-speech, and visual/motor-accessibility preferences.

This is a usability prototype, not a clinical AAC device or a replacement for an individualized AAC assessment. It stores no messages or personal data and uses only browser-native speech synthesis.
