# Clearvoice AAC MVP

## Development status — 14 September 2026

**Paused — not in active development.**

Parent Decoder is the only project in active development until it is finished. This prototype is retained as reference material. Its existing implementation is not scheduled for continued development. Any future work requires a deliberate new priority after Parent Decoder is finished; there is no scheduled restart or commitment to finish this version. Earlier feature plans below are historical possibilities, not an active roadmap.

---

A no-build, browser-based interactive AAC prototype. Open `index.html` in a modern browser.

It includes a stable core vocabulary board, quick and emergency phrases, a word finder, spelling mode, message composition with undo/clear, browser text-to-speech, and visual/motor-accessibility preferences.

This is a usability prototype, not a clinical AAC device or a replacement for an individualized AAC assessment. It stores no messages or personal data and uses only browser-native speech synthesis.
