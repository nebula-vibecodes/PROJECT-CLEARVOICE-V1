---
name: Places symbol audit
description: Criteria for assigning Mulberry artwork to Clearvoice Places vocabulary.
---

Use a Mulberry symbol for a Places tile only when it directly represents the complete location label. Keep Work text-only when the catalog offers only an office-building depiction, keep Park text-only when only a parking action exists, and keep Here/There/Far and compound travel or direction phrases text-only when only partial position or question symbols are available.

**Why:** AAC location symbols must distinguish actual places from actions, generic buildings, relative positions, and navigation requests. A nearby-looking symbol can change the intended meaning.

**How to apply:** Compare the full label and spoken output with the catalog name and depiction. Existing exact mappings such as Home, School, Bathroom, Outside, Room, Store, Near, and Inside should remain stable.
